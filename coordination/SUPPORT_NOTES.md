## Support note — Edge default browser popup

### Symptom
A Microsoft Edge system popup appears asking to use recommended browser settings / set Edge as default browser.

### Interpretation
This is an OS/browser promotional popup, not a project-specific blocker for the Oakfarm clone task.

### Required action
- Do NOT treat this popup as part of the website clone workflow.
- Dismiss/close it and continue working.
- Do not spend task time trying to solve Edge default-browser promotion flows.
- Keep focus on the current project task only.

### If it interferes repeatedly
- Close the popup/window.
- Return focus to the project editor/browser tabs relevant to `oakfarm.vn` and `localhost:3000`.
- Continue Task 005 (homepage round-2 polish and responsive behavior).
